## 📌 Project Overview

I created this case study to demonstrate how I would plan, coordinate, monitor, and manage an AI-powered software project using practical Project Management frameworks.

### The Project

**AI Customer Support Platform** — a simulated B2B SaaS product that helps online retailers automate routine customer-support conversations while maintaining human escalation and control.

The platform is designed to:

- Answer customer questions using an approved knowledge base
- Provide sources with AI-generated answers
- Escalate conversations to human agents
- Preserve conversation context during escalation
- Allow administrators to manage knowledge-base content
- Provide basic support analytics
- Protect customer and business data

## 🎯 Project Objective

The simulated objective was to plan a 10-week pilot delivery of an AI customer-support platform that could:

1. Answer questions using approved knowledge-base content
2. Provide sources for AI-generated answers
3. Escalate complex or low-confidence conversations to human agents
4. Allow administrators to manage support content
5. Provide basic analytics
6. Protect customer information

### Proposed Project Targets

These are **planning targets for the simulation, not actual project results**.

- At least 35% of conversations resolved without human handover within 8 weeks of go-live
- AI responses within 8 seconds or less at p95
- At least 85% golden-set accuracy before go-live
- No more than 5% unsupported answers before go-live
- Pilot release planned for 11 March 2026

# ⚠️ Risk Management

The simulated project contains **17 identified risks** across areas including:

- AI hallucination
- Knowledge-base quality
- Privacy and security
- Scope creep
- LLM/API dependency
- Cost
- Technical dependencies
- Delivery constraints

Risks are evaluated using probability and impact and include:

**Owner → Trigger → Mitigation → Contingency → Residual Risk → Status**

This demonstrates how I would move beyond simply listing risks and instead establish a process for monitoring and responding to them.
